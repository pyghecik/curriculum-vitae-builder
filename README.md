# | Curriculum Vitae Builder

A free web-based CV builder that allows users to customize the appearance of their CVs. In this tough times I wanted for people to have a decent free [Resume/CV Creator](https://pyghecik.github.io/curriculum-vitae-builder/)!

## | 🛠️ Technologies Used:
- Base: Vite.js using TypeScript and React
- Styles: Tailwind CSS
- Data Storage library: Zustand
- Draggable elements: dnd kit
- PDF export: react-to-print

## | 🤖 AI-Assisted Development

AI tools were used to support the development process:

- **GitHub Copilot** — Assisted with code implementation directly in VS Code.
- **Claude** — Helped evaluate technology choices and identify an appropriate tech stack for the project.

AI-generated suggestions were reviewed, and manual fixes were made where necessary.

Technology choices were based on my existing knowledge, project requirements, and discussions with Claude.

## | 🎯 Project Purpose

The project was initially developed to meet my own CV creation needs. I later decided to make it publicly accessible so that others could use it as well.

This project also provided an opportunity to apply my knowledge of React and TypeScript while exploring AI-assisted development workflows.
