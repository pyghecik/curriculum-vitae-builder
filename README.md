# | Curriculum Vitae Builder

In this tough times I wanted for people to have a decent free [Resume/CV Creator](https://pyghecik.github.io/curriculum-vitae-builder/)!

# | Planned future updates:
- none

# | Technologies used:
- Base: Vite.js using TypeScript and React
- Styles: Tailwind CSS
- Data Storage library: Zustand
- Draggable elements: dnd kit
- PDF export: react-to-print
